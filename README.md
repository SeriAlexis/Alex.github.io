# 🥧 Сайт-визитка пекарни "Nadina Kuhinja"

Одностраничный сайт для семейной пекарни. Создан в рамках учебного проекта по вёрстке с нуля. Код — полностью мой, дизайн - адаптированный шаблон из Canva.

## ✨ Функционал

- Представление основных видов продукции (с выезжающей галереей)
- Адаптивная вёрстка: корректно отображается на телефонах, планшетах и компьютерах

## 🛠️ Технологии

- **HTML5, CSS3** (Flexbox, Grid, медиазапросы)
- **GitHub Pages** для публикации
